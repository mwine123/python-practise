## Accessing Dictionary Values

Dictionary content can be accessed by keys. To retrieve a value from a dictionary, you can specify it's corresponding key in square brackets([]) after the dictionary name:
Eg: >>> MLB_teams["Minnesota"]
    'Twins'
When you refer to a key that isnt in the dictionary, Python raises an exception. If the key doesnt exist in the dictionary, you get a KeyError exception.
